# 🎮 Eldoria Quest

**Eldoria Quest** is a 2D narrative-driven educational adventure game built with **Unity 2022.3.58f1**.  
The game combines storytelling, exploration, and lightweight combat to promote moral education and ethical decision-making in a fantasy world designed for young audiences.

---

## 📌 Features

- 🌍 Branching dialogues with multiple moral outcomes
- 🗣️ NPC interactions with modular dialogue trees
- ⚔️ Light combat system with destructible environment objects
- 💰 Coin-based economy and interactive HUD
- 🎧 Persistent audio and scene transitions using Singleton Managers
- ⏸️ Pause menu with settings control
- 🖼️ Pixel-perfect visuals using Unity’s Pixel Perfect Camera

---

## 🛠️ Development Environment

- **Engine:** Unity 2022.3.58f1 (LTS)
- **Language:** C#  
- **Dependencies:** None (no external plugins or libraries)

> ⚠️ Be sure to use the specified Unity version for full compatibility.

## 🚀 Getting Started

### 🔧 Run the Project in Unity

1. Download or clone the project:
   
   git clone https://github.com/Irj20022/Eldoria-Quest.git

3. Open **Unity Hub**, click **"Open"**, and select the project directory.

4. Open the `MainMenu` scene and press ▶️ to play in the Unity Editor.

---

### 🎮 Play the Game (Windows Build)

1. Download the ZIP from the `Releases` section.
2. Extract it using **WinRAR** or **7-Zip**.
3. Double-click `EldoriaQuest.exe` to launch the game.

## 🎮 Controls

| Action                  | Key           |
| ----------------------- | ------------- |
| Move                    | W / A / S / D |
| Interact with NPCs      | E             |
| Attack / Destroy Object | Spacebar      |
| Pause / Settings        | ESC           |

## 📂 Project Structure

```
EldoriaQuest/
├── Assets/
│   ├── Animations/           # Animator Controllers and keyframe animations
│   ├── Audio/                # Background music and sound effects (SFX)
│   ├── Materials/            # Materials used for visual effects or UI shaders
│   ├── Prefabs/              # Reusable GameObject prefabs (e.g., NPCs, UI panels)
│   ├── Scenes/               # Game scenes like MainMenu, Town, Forest, etc.
│   ├── Scriptable Objects/   # SOs used for dialogues, items, or settings
│   ├── Scripts/              # All C# scripts (Managers, Systems, etc.)
│   ├── Settings/             # Unity settings assets
│   ├── Sprites/              # 2D assets such as characters, items, backgrounds
│   ├── TextMesh Pro/         # TextMeshPro resources and font assets
│   └── Tilemap/              # Tilemap assets for level design
├── ProjectSettings/
├── Packages/
├── README.md
└── EldoriaQuest.sln
```
